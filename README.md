# normal-gen

![Bash](https://img.shields.io/badge/Bash-4EAA25?logo=gnubash&logoColor=white)
![Platform](https://img.shields.io/badge/platform-Linux%20%7C%20macOS%20%7C%20WSL-lightgrey)

Интерактивный Bash-скрипт для **генерации и анализа нормально распределённых случайных величин**. Три метода генерации, статистика и текстовая гистограмма — прямо в терминале, без Python и R.

## Возможности

- **Три метода генерации** на выбор (см. ниже).
- **Параметры распределения:** количество чисел, математическое ожидание μ, стандартное отклонение σ и `seed` для воспроизводимых результатов.
- **Вывод** чисел на экран (при количестве больше 100 числа не выводятся, чтобы не засорять терминал) и **сохранение** в файл.
- **Статистика** выборки: среднее, дисперсия, минимум и максимум.
- **Текстовая гистограмма** распределения.

## Методы генерации

| Метод | Суть |
|---|---|
| Бокса–Мюллера | две равномерные величины преобразуются в нормальную |
| Неймана | метод исключения (rejection sampling) |
| Марсальи–Брея | полярный вариант метода Бокса–Мюллера |

## Параметры по умолчанию

| Параметр | Значение |
|---|---|
| Количество чисел | 100 |
| μ (математическое ожидание) | 0.0 |
| σ (стандартное отклонение) | 1.0 |
| Метод | Бокса–Мюллера |

## Установка и запуск

```bash
git clone https://github.com/woqowieowww/normal-gen.git
cd normal-gen
chmod +x normal_gen.sh
./normal_gen.sh
```

Скрипт работает в интерактивном режиме и показывает меню:

| Пункт | Действие |
|---|---|
| 1 | Задать параметры генерации |
| 2 | Выбрать метод |
| 3 | Сгенерировать и вывести числа |
| 4 | Сохранить результат в файл |
| 5 | Показать статистику |
| 6 | Показать гистограмму |
| 7 | О программе |
| 8 | Выход |

### Типичный сценарий

1. Пункт **1** — задайте, например, 1000 чисел, μ = 50, σ = 10.
2. Пункт **2** — выберите метод.
3. Пункт **3** — сгенерируйте выборку.
4. Пункты **5** и **6** — посмотрите статистику и гистограмму; среднее и σ должны оказаться близки к заданным.
5. Пункт **4** — сохраните выборку в файл.

## Как читать гистограмму

Каждая строка — один интервал:

```text
[ левая граница - правая граница ] |*****…  (число значений)
```

Длина строки из `*` пропорциональна доле значений в интервале: 50 звёздочек соответствовали бы всей выборке, то есть одна звёздочка — около 2 % значений.
